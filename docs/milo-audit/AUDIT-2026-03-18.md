### Problemes trouves et corrections

| # | Probleme | Avant | Apres | Pourquoi |
|---|----------|-------|-------|----------|
| 1 | Opus sans cache | `cacheRetention: NOT SET` | `"long"` | Cache perdu quand Kevin switch sur Opus |
| 2 | Heartbeat sur Gemini | `google/gemini-2.5-flash` | `anthropic/claude-haiku-4-5` | Heartbeat ne gardait pas le cache Claude chaud |
| 3 | Compaction trop tardive | `reserveTokensFloor: 40000` | `50000` | Cause du crash 412k — compaction se declenchait trop tard |
| 4 | Memory flush trop tard | `softThresholdTokens: 40000` | `6000` (default doc) | Flush memoire avant compaction arrivait trop tard |
| 5 | Tools profile manquant | `NOT SET` | `"full"` | Limitait les outils disponibles |
| 6 | Context pruning TTL trop long | `6h` | `1h` (default doc) | 6h de vieux tool results = bloat contexte |
| 7 | Heartbeat ackMaxChars | `50` | `300` (default) | Trop court pour un resume utile |
